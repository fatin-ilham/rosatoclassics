# Logo Setup Instructions

## Your Logo File

The logo you provided should be saved as: `images/logo.png`

## Steps:

1. **Save your logo image** to the project folder:
   - Copy your logo PNG file
   - Paste it into: `C:\Users\User\Downloads\First Program\rosato-sneakers\images\logo.png`

2. **Logo specifications** (for best results):
   - Format: PNG with transparent background
   - Size: Approximately 200x80 pixels (or any size with similar aspect ratio)
   - The logo will display at 40px height in the header, 30px in footer

3. **Current logo styling:**
   - Header: 40px height, auto width
   - Footer: 30px height, auto width
   - Hover effect: Slight opacity change (0.8)

## If logo doesn't appear:

- Check that the file is named exactly `logo.png` (case-sensitive on some servers)
- Verify the file is in the `images/` folder
- Clear browser cache and refresh

## Logo Usage:

The logo appears in:
- Header navigation (all pages)
- Footer (all pages)

Both locations use the same `images/logo.png` file.
